## 0. 术语提醒（查规则必读）

手册**没有**"上位机"这个技术术语——全库扫描只在参赛手册 p11"人员方向"表里出现一次。
技术条款用两个词：

- **运算平台** —— 电脑本体（选型 / 操作系统条款）
- **Mini PC** —— 电源管理模块 [9] 号输出接口的名字（供电条款）

## 1. 上位机（运算平台）官方条款

### 1.1 选型与算力 —— 制作规范 2.3（p25-26）

- **S65**：禁止第三方成品模组/成品系统（主板、CPU、GPU、内存、硬盘都在"成品模组"定义内）
- 市售通用产品豁免：①公开销售 ②通用用途（非赛事定制——"RoboMaster 专用"反例）
- **运算平台豁免条件（价格 or 算力，满足其一即可）**：
  - 价格条件：≤8000 元（同成品系统）
  - 峰值算力条件：加速算力 ≤**160 TOPS**（AI TOPS INT8 稀疏值）**且** 通用算力 ≤**25GHz**（Σ(主频×核数)）
- **雷达运算平台端、自定义终端** 使用的运算平台**不受此条例限制**
- 组委会可要求发票/官网页面/认证等材料佐证 → **选型时留档**
- ⚠️ 待办：把候选机型按此口径逐一核对并留证

### 1.2 操作系统 —— S60（p21）

运算平台如使用操作系统必须**开源**（Linux 及衍生、RTOS ✓；**Windows/macOS ✗**）

### 1.3 供电 —— 电源管理模块（p56-59 + RMUL 规则 p13）

- **Mini PC 专用 XT30 输出**（接口 [9]）；哨兵四路供电：Chassis / Gimbal / Ammo-Booster / Mini PC
- **战亡后裁判系统切断电源输出——唯 Mini PC 除外** ⇒ 死亡/读条期间上位机不断电
- 接入供电接口的用电器在接口断电时需立即断电；继电器必须走对应接口（否则视为作弊）
- 9-12 号输出口电压波动 → 手册**建议对 Mini PC 做稳压**

### 1.4 无线/调试限制（涉及上位机调试链路）

- **R3**（RMUL p55）：不得在比赛相关区域自行架设无线设备
- **R46**（RMUL p60）：不可将**无线调试器**带入赛场
- **S50**（spec p19）：**自定义终端不得使用无线发射/接收装置**
- ⇒ 调试链路按"有线"设计；赛中无 WiFi

### 1.5 自定义终端（若做地面站）

- 最大 30V；收纳 600×600×600；图传 UDP；比赛数据 MQTT+ProtoBuf；S47 禁止双面胶/螺丝接触操作间桌面
- 其运算平台不受成品模组限制（见 1.1）

### 1.6 传感器 / 定位（关键结论）

- spec p29：**"定位模块（RMUL 不适用）"**；p48：**"在 RMUL 中，机器人不需要安装定位模块"**
- ⇒ **RMUL 无官方定位数据，哨兵必须自定位（SLAM）** → 双 Mid-360 方案成立且必要
- 全库扫描：RMUL 手册**无**激光雷达/传感器禁令（"激光雷达" 0 命中，"雷达" 0 命中）

### 1.7 视觉相关制作规范（顺带）

- 增加"视觉模块" = **非充分再设计**（走报备/唯一标识流程，spec p23）
- S17：板面 >10×20mm 区域光泽度 ≤30Gs（光轴/镜头除外）
- 图传发送端安装规范 spec 3.9（p80-83，含禁止遮挡区域图）——装相机前必读
- 相机图传模块是**官方机载模块**（哨兵 1 个）——第一视角图传，与自瞄相机无关

## 2. 3V3 哨兵 2027 机制（与环境对齐清单）

### 2.1 哨兵关键参数（RMUL 规则 3.1.3，p21-22）

| 项 | 值 |
|---|---|
| 运行方式 | **全自动**（最多 1 个调试遥控器，赛前交出，R22 p57） |
| 多机通信 | **不允许** |
| 初始/上限血量 | 400 |
| 底盘功率上限 | 100 W |
| 射击热量 | 上限 260，冷却 30/s |
| 射击 | 17mm，初速上限 25 m/s |
| 允许发弹量 | 750，**局内不可增加** |
| 可激活 | 控制区、补给区增益点 |
| 回血 | 补给区，基础 25%/s |
| 复活 | 读条复活 |

### 2.2 复活机制（3.3.2.2，p36）—— 环境照抄用

- 战亡：射击热量清零、缓冲能量重置
- 自动复活：每秒 +1 读条；**首次读条长度 5，每次战亡后 +5**（5/10/15/20…）
- 复活后：血量 = 20% 上限、无敌 30 s、进入**虚弱**
- 虚弱：发射机构锁定 + **无法激活控制区**
- 检测到己方补给区场地交互模块卡 → 虚弱 + 无敌解除

### 2.3 控制区 / 控制度（3.3.4，p37-38）—— 取代旧"胜利点"

- **3 组控制区**：红方高地 / 蓝方高地 / 中央（开局均中立）
- 占领进度：每方对每处独立 0~5；计满 5 = 控制，减至 0 = 失去
  - 独占激活且对方进度为 0：己方 +1/s
  - 独占激活且对方进度 ≠0：对方 -1/s
  - 双方同激活：暂停；双方均不激活且非中立：双方 -1/s
- **控制度各 600**：每控制 1 处，对方 -1/s（最多 3/s）；**机器人战亡，己方 -10**
- 差值 ≥200：劣势方复活读条 -33%、补给区回血 33%/s
- 差值 ≥400：读条 -50%、补给区回血 50%/s
- 差值首次到 200 或 400：劣势方 +200 金币（每局上限 400）

### 2.4 其它场地/机制

- 高地增益点 = 高地控制区；激活得 25% 防御（手册原文"双方机器人均可激活双方高地增益点"，语义待精读图确认）
- 隧道增益：同一机器人 3 s 内检测到一侧两处隧道增益点且中途无其他交互卡 → 1.5× 热量冷却，持续 60 s
- 控制区、补给区、隧道交互卡上**额外铺一层地胶**
- 经济：开局 200 金币 + 定期发放（04:59/03:59/02:59 +200，01:59/00:59 +300）；**只有重装/步兵**可兑换发弹量（17mm：10 金币/10 发）
- 重装 42mm 屏蔽机制：重装战亡/超发/失联时对方装甲屏蔽 42mm 伤害（17mm 不受影响）
- 赛制：3 分钟准备 + 5 分钟比赛
