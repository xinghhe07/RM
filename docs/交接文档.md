## 5. 设计（见 `哨兵方案设计.md`）

**三层决策**：RL（上限）→ 规则/行为树（兜底）→ 最低安全策略。切换全自动。

| 层 | 方案 | 借鉴 |
|---|---|---|
| 底盘 | 全向轮（4 轮 X 型）解算 | **`rm-controls/rm_control`（BSD-3；与麦轮同构，符号标定后复用——见 `哨兵方案设计.md` §1.2）** |
| 定位 | 双 Mid-360 无盲区 | `pb2025_sentry_nav`（Apache-2.0）+ Point-LIO/FAST-LIO2 |
| 导航 | Nav2 | 同上 |
| 决策 | 规则→行为树→RL | `pb2025_sentry_behavior`（Apache-2.0）+ 自研环境 |
| 训练范式 | 照搬 | `zeitvex/RC_WheelLeg`（MIT） |

**照搬的范式**：非对称 actor-critic（critic 看全局特权信息）、课程学习、域随机化、ONNX 契约。
**关键简化**：全向底盘不用学"怎么走" → **RL 只学战术决策**。
